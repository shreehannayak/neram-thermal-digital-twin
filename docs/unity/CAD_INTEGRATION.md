# CAD integration (Neharikaa → Unity)

The scene binds data to geometry **by object name**. Any FBX that follows these names replaces the generated placeholders with no code change.

## 1. Coordinate frame and units
* Units: **metres**. Up: **+Y**. Origin: centre of the **table-top surface**.
* **+Z toward the patient's head**; patient supine (face +Y). In Unity's left-handed frame the **patient's left is +X**.
* Export each object already placed in this frame (the integration tool keeps CAD positions). Check scale against `Reference_Cube_1m` (enable it in the scene; 1 m edge).
* FBX export: *Units = m, Y up, Apply transforms*. Blender: Forward −Z/Up Y with *Apply Unit* and *Apply Transform*; SolidWorks/Fusion: export meters.

## 2. Required names
Top-level objects (exact names; one FBX may contain several):

| Role | Children (exact names) |
|---|---|
| `Left_Hand_Module` (CH1) | `CH1_Liner`, `CH1_Sensor_A`, `CH1_Sensor_B`, `CH1_Heater`, `CH1_Cutoff`, `CH1_Insulation`, `CH1_Shell`, `CH1_Strain_Relief`, `CH1_Strap_1` … `CH1_Strap_n` |
| `Right_Hand_Module` (CH2) | same with `CH2_` |
| `Left_Foot_Module` (CH3) | same with `CH3_` |
| `Right_Foot_Module` (CH4) | same with `CH4_` |
| `Bedside_Controller` | `BC_Enclosure`, `BC_Front_Panel`, `BC_Display`, `BC_LED_CH1`…`BC_LED_CH4`, `BC_Button_Start`, `BC_Button_Stop`, `BC_Button_Reset`, `BC_Port_CH1`…`BC_Port_CH4`, `BC_Mains_Inlet`, `BC_Rail_Clamp` |
| `Cable_CH1` … `Cable_CH4` | `Connector_CH1` … (the plug at the controller end) |
| `OR_Table`, `Patient_Mannequin`, `Cable_Hub` | free (not data-bound) |

What each name drives (only replayed values):
* `CHn_Heater` renderers: emission ∝ `Heat_n` (%). **Must be a separate mesh** and its material must support emission (`MAT_Heater`).
* All module meshes: fault outline when `Channel_Fault_n ≠ 0`, `HW_Cutoff_n` or `Module_Connected_n = 0`.
* `CHn_*` layers: exploded view along the module's local +Y (away from skin) — order Liner → Sensors → Heater → Cutoff → Insulation → Shell → Straps. Exact offsets optional in `cad/exploded_offsets.csv` (`object,dx_m,dy_m,dz_m`; dy used).
* `BC_LED_CHn`: channel display status colour. `BC_Display`: controller-state colour.
* `Connector_CHn`: drops 3.5 cm when `Module_Connected_n = 0`.

Material slots named `MAT_Liner, MAT_Sensor, MAT_Heater, MAT_Insulation, MAT_Shell, MAT_Strap, MAT_Cable, MAT_Connector, MAT_Enclosure, MAT_Indicator` are swapped for the project materials automatically.

## 3. Steps
1. Put the FBX files in `unity/Assets/NERAM_CAD/` (import settings are applied automatically: scale 1, file scale, readable meshes, no animation/cameras/lights; a warning is logged if bounds don't look like metres).
2. Open `Assets/Scenes/NERAM_OR_Replay.unity`.
3. Select the imported model(s) in the Project window → **NERAM → CAD → Integrate selected CAD models**. Each role object is placed under `NERAM_Assembly` with its exact name; matching `*_PLACEHOLDER` objects are disabled. A report lists missing parts.
4. Save the scene → **NERAM → 4. Validate project** (modules without `CHn_Heater` are FAIL; other missing parts WARN).
5. Optional: copy `exploded_offsets.csv` to `cad/` and run **NERAM → 2. Sync**.
6. Diagnostics drawer → "3D assembly" shows CAD vs PLACEHOLDER per role at runtime.

Rollback: delete the CAD object under `NERAM_Assembly` and re-enable the `*_PLACEHOLDER`, or rerun *NERAM → 3. Rebuild placeholder scene*.

## 4. What the placeholders are
Primitive stand-ins generated by `NeramSetup.cs`, each with a `PlaceholderMarker`. Their dimensions are **not** design values and must not be quoted. Placeholder layer stack (per module): liner, two sensors, heater, cutoff, insulation (transparent), shell (transparent), two straps, strain relief.
